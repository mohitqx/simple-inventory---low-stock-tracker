# Simple Inventory & Low-Stock Tracker

A lightweight CLI application written in C that simulates a warehouse inventory management system. 

##  Features
* **Low-Stock Alerts:** Automatically identifies and highlights items with fewer than 5 units.
* **Out-of-Stock Tallies:** Counts the total number of items completely sold out.
* **Automatic Restocking:** In-place array modification that detects out-of-stock items and updates their quantities.

##  Concepts Applied
* Array traversal and in-place modification
* Conditional statements inside loops
* Multi-loop program structuring in C
